# 📝 Create Topic Bot

A Telegram bot that helps users create and manage topics with titles, descriptions, categories, and deadlines.

## ✨ Features
- Create topics with title and description
- Categorize topics (Work, Personal, Study, Other)
- Set optional deadlines
- View all created topics
- Delete topics
- Clean, user-friendly interface with buttons

## 🚀 Quick Deploy on Railway

[![Deploy on Railway](https://railway.app/button.svg)](https://railway.app/template/deploy)

### Manual Deployment

1. Fork this repository to your GitHub account
2. Login to [Railway.app](https://railway.app)
3. Click "New Project" → "Deploy from GitHub repo"
4. Select this repository
5. Add environment variable:
   - `TELEGRAM_BOT_TOKEN` = Your bot token from @BotFather
6. Deploy!

## 🛠️ Commands
- `/start` - Welcome message
- `/new` - Create a new topic
- `/my` - View all your topics
- `/delete` - Delete a topic
- `/help` - Show help
- `/cancel` - Cancel current operation
